الوصف.
أداة مبتكرة طُورت باستخدام لغة Python ومكتبة ArcPy لتنفيذ عمليات التحول الرقمي لمشاريع البنية التحتية. تهدف الأداة إلى تحويل شبكات الصرف الصحي من مخططات AutoCAD إلى بيئة ArcGIS Pro بدقة متناهية (100%)، مع معالجة البيانات هندسياً وتحديد اتجاهات السريان آلياً.

المميزات الرئيسية.
التحويل الذكي: تحويل تلقائي للخطوط (Pipes) والنقاط (Manholes) مع نقل كامل البيانات الوصفية.

تحديد اتجاه السريان: حساب اتجاه السريان (Flow Direction) هندسياً داخل الشبكة دون تدخل بشري.


معالجة الرموز الفنية: القدرة على قراءة الرموز الهندسية المعقدة مثل الأقطار (Ø) وتحويلها لبيانات رقمية.

ضمان جودة البيانات: التخلص من الأخطاء الناتجة عن الإدخال اليدوي لضمان مطابقة البيانات للمعايير الهندسية.

محتويات المشروع.
Geospatial Engineering Utilities.pyt: الأداة البرمجية (Script Tool) المخصصة للعمل داخل ArcGIS Pro.

دليل الاستخدام: ملف PDF يشرح بالتفصيل طريقة التشغيل ومعايير تسمية الطبقات لضمان أفضل نتائج
